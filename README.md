# Idle RPG

A simple clicker game where you gain experience points (XP) and level up.

## How to Play

1.  Open the `index.html` file in your web browser.
2.  Click the "Gain XP" button to earn 1 XP per click.
3.  Watch your XP and level increase!
4.  Your progress is saved automatically in your browser.

## Features
*   Gain XP by clicking a button.
*   Level up after accumulating enough XP.
*   Visible progress bar for XP.
*   Data persistence using browser localStorage.
